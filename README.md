# Vasallo94/scoop-bucket

[Scoop](https://scoop.sh) manifests for my apps.

```powershell
scoop bucket add vasallo94 https://github.com/Vasallo94/scoop-bucket
scoop install redlights
```

| App | What it is |
|---|---|
| [`redlights`](https://github.com/Vasallo94/redlights) | Turns every display pure red for astronomy |

Manifests update automatically every day from each app's latest GitHub release, and every change is tested by installing it on a Windows machine.
